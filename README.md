# MOR — Mortis Imperium Alliance Hub

A responsive static landing page for the MOR alliance, ready to publish with GitHub Pages.

## Files

- `index.html` — the landing page
- `assets/mor-emblem.jpg` — MOR dragon/reaper emblem
- `assets/mor-alliance-playbook.png` — MOR Alliance Playbook poster

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `mor-alliance-hub`.
2. Upload the contents of this folder to the repository's root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.

No build step, framework, or dependencies are required.
